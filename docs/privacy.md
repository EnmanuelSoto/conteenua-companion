# Privacy

## Stays on the computer by default

- repository files and local filesystem paths;
- shell environment and local processes;
- ChatGPT browser credentials and cookies;
- operating-system secrets;
- full local session journals and terminal output.

## Stored in Conteenua cloud

- paired-device ID/name/platform and online status;
- approved project's display name, local project ID, optional Git remote metadata and capability flags;
- remote instructions the user sends from Conteenua;
- session/provider/status metadata;
- explicit approval requests/decisions;
- bounded safe activity summaries such as "ChatGPT started working" or "Using exec_command".

Conteenua Companion's local mode is not intended to upload a repository as a prerequisite for coding.
