## Conteenua Companion 0.1.0 — private beta

This is the first public-source private beta of Conteenua Companion, the local execution layer for Conteenua's **Use your own AI** coding path.

### Included

- Conteenua-branded Windows/macOS/Linux desktop companion and browser extension.
- Approved local projects with path-safe filesystem tools and local terminal/process execution.
- Normal-ChatGPT provider adapters with official MCP where the user's ChatGPT workspace supports writable tools and a separate browser bridge adapter.
- Outbound-only Conteenua device/session control through owner-scoped Supabase data and Realtime.
- Remote start/follow-up/pause/resume/stop/open-session controls and safe activity summaries.
- One-shot, command-fingerprinted approval gates for package installs, Git pushes, deployments, recursive deletes, and destructive commands.
- Explicit **0 Conteenua AI credits** separation for the bring-your-own-AI path.
- Conteenua Companion Core connector setup shown directly in the companion UI.
- Persistent OpenAI tunnel setup is exposed directly in the slim Companion UI, including tunnel-ID validation and OS-backed secure storage for the restricted tunnel key. This is the recommended restart-safe ChatGPT connector path.
- Cloudflare quick-tunnel readiness is verified with a real public MCP initialize round-trip before the UI reports connected.
- Cloudflare cloudflared 2026.9.1 is pinned independently from OpenAI tunnel-client v0.0.14.
- Real provider acceptance completed against a signed-in ChatGPT Pro account in ordinary **Chat** mode: the developer MCP app discovered `read`, `apply_patch`, `exec_command`, `write_stdin`, and `update_plan`; a normal-Chat read call reached the local repo; a Conteenua-originated remote session wrote and verified a disposable local file; and a Conteenua follow-up continued the same normal Chat conversation. Stop/cancel terminal-state behavior is covered by focused Companion regression tests.
- The live BYO-AI acceptance produced zero Conteenua credit-ledger entries and zero credit amount.
- Cloud project metadata is reconciled against the current local project catalog, and cancelled/paused remote states are protected from later sync bounce.

### Beta limitations

- Windows and macOS artifacts are not yet publisher-signed/notarized.
- The browser/quick-tunnel fallback still uses a temporary public URL. It is intentionally labeled a fallback; normal setup should use the persistent OpenAI tunnel so the installed ChatGPT developer app survives Companion restarts.
- Provider-side message/quota accounting remains controlled by ChatGPT. Conteenua can prove the accepted path is ordinary Chat mode rather than Work/Codex, but should not promise an exact provider-side message-count formula.
- Conteenua does not bypass ChatGPT plan/workspace limits and does not silently substitute Codex or Conteenua's paid AI executor.

This release remains a private beta/dogfooding build because installers are unsigned/unnotarized and browser-store distribution/onboarding is not yet finalized.
